# Настройка локальной LLM модели (LM Studio) для RAG Inference

## Проблема
При использовании локальной модели через LM Studio нужно указать:
1. **API URL** - адрес сервера LM Studio
2. **Идентификатор модели** - точное имя модели

## Решение

### ✅ Обновления в `rag_inference.html`

Добавлено новое поле **"Идентификатор модели"** для Custom API провайдера.

### 📝 Как использовать

1. **Запустите LM Studio на другом компьютере**
   - Загрузите модель (например, `qwen/qwen3-1.7b`)
   - Запустите локальный сервер
   - Убедитесь что сервер доступен по сети

2. **В интерфейсе RAG Inference:**
   - Выберите провайдер: **Custom API**
   - Укажите **API URL**: `http://192.168.1.155:1234/v1`
   - Укажите **Идентификатор модели**: `qwen/qwen3-1.7b`

3. **Задайте вопрос**
   - Выберите пайплайн
   - Введите вопрос
   - Нажмите "Задать вопрос"

### 🔧 Пример конфигурации

```
Провайдер: Custom API
API URL: http://192.168.1.155:1234/v1
Идентификатор модели: qwen/qwen3-1.7b
Top K документов: 5
Temperature: 0.7  ← Управляет креативностью ответов
```

### 🌡️ Параметр Temperature

**Temperature** управляет "креативностью" ответов модели:

- **0.0** - Детерминированные, точные ответы (рекомендуется для RAG)
- **0.3-0.5** - Слегка вариативные ответы
- **0.7-1.0** - Более креативные и разнообразные ответы
- **1.5-2.0** - Очень креативные, но менее предсказуемые

💡 **Для RAG рекомендуется использовать низкую температуру (0-0.3)**, чтобы модель строго следовала контексту из документов.

### 📋 Поддерживаемые форматы идентификаторов

- `qwen/qwen3-1.7b` - для Qwen модели
- `mistral-7b-instruct` - для Mistral
- `llama-2-7b-chat` - для Llama
- Любой другой идентификатор, который использует ваша модель

### ⚠️ Важно

1. **Убедитесь что URL заканчивается на `/v1`**
   - Правильно: `http://192.168.1.155:1234/v1`
   - Неправильно: `http://192.168.1.155:1234`

2. **Идентификатор модели должен точно совпадать**
   - Проверьте точное имя модели в LM Studio
   - Некоторые модели используют формат `owner/model-name`
   - Другие используют просто `model-name`

3. **Проверьте доступность сервера**
   ```bash
   curl http://192.168.1.155:1234/v1/models
   ```

### 🎯 Как это работает

При выборе **Custom API** и заполнении **Идентификатора модели**:

```javascript
// Код автоматически использует customModelId вместо стандартного model
if (provider === 'custom' && customModelId) {
    model = customModelId;
}

// Отправляется запрос с вашими параметрами
{
    "llm_provider": "custom",
    "llm_model": "qwen/qwen3-1.7b",  // Ваш идентификатор
    "custom_api_url": "http://192.168.1.155:1234/v1"
}
```
